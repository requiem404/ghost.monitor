# Ghost Monitor

Real-time dashboard for tracking spirit anomalies in Tokyo.

## Getting Started

## Docker
```bash
docker-compose up
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.


## Dev

```bash
# Install dependencies
npm install
# or
yarn

# Start development server
npm run dev
# or
yarn dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
